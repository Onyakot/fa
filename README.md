# Функціональний аналіз

Відкрита колекція навчальних матеріалів для вивчення **функціонального аналізу** та суміжних розділів математики.

Репозиторій містить лекційні матеріали, практичні завдання, питання для самоперевірки та добірку математичної літератури. Матеріали можуть використовуватися як для систематичного вивчення дисципліни, так і для самостійної роботи та поглиблення знань.

## Матеріали

- **[Лекції](lectures/lectures.md)** — теоретичні матеріали з основних розділів функціонального аналізу.
- **[Практичні завдання](practices/practices.md)** — задачі, вправи та приклади розв'язання.
- **[Питання для самоперевірки](exams/exams.md)** — теоретичні питання для закріплення й перевірки знань.
- **[Література](books/books.md)** — підручники, монографії та додаткові джерела.

## Основні теми

Матеріали охоплюють такі розділи:

1. Елементи загальної топології.
2. Метричні та повні метричні простори.
3. Компактність і неперервність.
4. Лінійні та нормовані простори.
5. Банахові та гільбертові простори.
6. Лінійні функціонали та оператори.
7. Спряжені простори та оператори.
8. Слабка топологія та слабка збіжність.
9. Основні принципи функціонального аналізу.
10. Компактні оператори та елементи спектральної теорії.

## Самостійне вивчення

Для послідовного опанування матеріалу рекомендується поєднувати вивчення теоретичних положень із розв'язуванням задач.

Лекційні матеріали формують теоретичну основу, практичні завдання допомагають засвоїти математичні методи, а питання для самоперевірки дозволяють систематизувати отримані знання.

Для поглибленого вивчення окремих тем можна звертатися до додаткової літератури.
